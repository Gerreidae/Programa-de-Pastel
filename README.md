## ⚙️ Requisitos del Sistema

Para garantizar que el audio de cumpleaños se reproduzca sin cuellos de botella y que la evasión del botón no tenga latencia, asegúrate de cumplir con los siguientes requisitos:

| Componente | Mínimos (Para sobrevivir) | Recomendados (Experiencia 4K a 240fps) |
| :--- | :--- | :--- |
| **Sistema Operativo** | Windows 7 | Windows 11 |
| **Procesador (CPU)** | Intel Celeron o AMD Athlon | Intel Core Ultra 9 o AMD Ryzen 9 |
| **Memoria (RAM)** | 2 GB | 32 GB DDR5 |
| **Gráficos (GPU)** | Intel HD Graphics o Radeon Vega | NVIDIA GeForce RTX 5090 |
| **Almacenamiento** | 80 MB de espacio disponible | 1 TB de espacio libre (SSD M.2 NVMe) |

---
**Instrucciones de instalación:**
1. Descarga el archivo `.zip` desde la sección de **Releases**.
2. Extrae todos los archivos en una misma carpeta.
3. Ejecuta `Programa de Pastel.exe`.
4. Acepta el pastel.
